# Abdul Momin Alam — Portfolio

Personal portfolio site: projects, experience and contact.

Live at **https://abdulmominalam.github.io**

A single static page (`index.html`) with no build step. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## Deploy

Pushing to `main` publishes the site through GitHub Pages.
